# VoiceTools for Windows

[English](README.md) | 简体中文

基于 C# / UWP 的 Windows 本地声音练习与音高分析应用。参考 [DevExtras Voice Tools](https://devextras.com/voicetools/) 的使用流程独立实现，是非官方项目，与 DevExtras 无隶属或背书关系。

## 功能

- **实时音高**：启动后自动进入 Voice 页面并采集麦克风，显示滚动音高曲线、输入电平和音高统计。
- **最近录音回听**：支持回听最近 5、10、20 或 30 秒，默认 10 秒。灰线标记录音起点，红线标记播放进度。
- **音调练习**：按住 F♯2 至 F4 的 24 个音符按钮试听参考音，同时持续分析麦克风输入。标准音为 A4 = 440 Hz。
- **完整录音分析**：朗读文本录音或导入支持的 WAV 文件，查看音高统计及固定区间的时长占比，支持回听与导出。
- **比例尺**：ERB（默认）、Mel、Linear 实际改变曲线坐标、网格间距和色带位置，频率读数始终以 Hz 显示。
- **按语言区分内容**：支持简体中文和英文界面，各有独立的朗读文本和建议语句库。
- **自定义建议语句库**：独立编辑页面，每行包括编号、单行文本框和删除按钮，底部提供新增与保存按钮。仅可编辑当前语言的库。
- **音频设备选择**：可指定接收、播放设备，或使用系统默认设备。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 2004，内部版本 19041 或更新版本 |
| 开发环境 | Visual Studio 2022，安装 UWP 开发组件 |
| Windows SDK | 10.0.22621.0 |
| 自动检查 | PowerShell 7（`pwsh`） |

## 构建与运行

1. 在 Visual Studio 中打开 `VoiceTools.sln`。
2. 还原 NuGet 包。
3. 选择 **Debug / x64 / 本地计算机**，通过 Visual Studio 部署运行。
4. 根据提示允许访问麦克风。如采集失败，请检查 Windows 麦克风隐私设置及所选输入设备。

也可以在 Visual Studio 开发者终端中分别执行还原与构建：

```powershell
MSBuild.exe VoiceTools.csproj /t:Restore /p:Configuration=Debug /p:Platform=x64
MSBuild.exe VoiceTools.csproj /t:Build /p:Configuration=Debug /p:Platform=x64 /p:AppxBundle=Never
```

安装包输出到 `AppPackages/`。当前项目已启用签名，引用 `VoiceTools_TemporaryKey.pfx`。开发证书不代表公共信任；对外分发时请配置自己的签名证书，不要公开签名私钥。

打包可能出现已知的 `PRI257` 语言资源警告，涉及默认语言与依赖资源语言。编译成功不代表已经完成设备实测。

## 使用方法

### 实时声音与回听

应用启动后自动进入 Voice 页面并开始采集。随着回听窗口填满，录音起点灰线从右向左移动；窗口满后停在最左侧。

点击回听按钮播放当前可用录音，曲线冻结，红色进度线向右移动。**播放过程中再次点击按钮，会立即停止、清空当前录音与曲线，并重新录音。** 播放结束或点击“继续录音”也会开始新的一段录音，不是暂停后继续播放。

### 音调练习

从侧面汉堡菜单进入音调页，使用鼠标、触摸，或在按钮获得焦点后按住空格／回车试听。松开即停止。页面频率与音名来自麦克风实时分析。建议使用耳机，避免参考音被麦克风再次拾取。

### 朗读分析

进入分析页，查看或编辑朗读文本，点击“录制全文”；完成后点击“停止并分析”。分析使用完整录音文件，不受实时页 30 秒缓冲上限限制。

支持导入 **8–96 kHz、单声道或双声道、16 位 PCM WAV**，包括 PCM WAVE_FORMAT_EXTENSIBLE。不支持压缩 WAV、MP3 或 M4A。

### 设置与建议语句库

设置支持语言、性别／色块标记、比例尺、回听时长、分析待读文本以及接收／播放设备。

点击“建议语句库”进入独立页面，直接编辑不自动换行的文本框，点击 **＋** 新增一行，点击每行右侧按钮删除。修改完成后点击**保存**才会生效。空白行需要填写或删除；允许保存完全为空的语句库。未保存的修改不会生效。

编辑页仅显示当前应用语言的语句库。要编辑另一种语言，请先回到设置切换应用语言。返回 Voice 页面后，会读取该语言已保存的语句库。

## 分析方式

音高检测采用本项目的归一化自相关实现，并非原版内部算法。固定参考区间如下：

| 区间 | 参考颜色 |
| --- | --- |
| 85 ≤ Hz < 165 | 蓝色 |
| 165 ≤ Hz < 180 | 灰色 |
| 180 ≤ Hz ≤ 310 | 粉色 |
| 其他可靠检测到的音高 | 参考区间外 |

完整录音的区间占比以可靠检测到音高的总时长为分母。静音与无法识别的帧仅影响覆盖率，不计入区间占比。四类占比在四舍五入前合计为 100%。平均音高按有效时长加权，中位数和分位数使用有效帧计算。

区间阈值和颜色不提供自定义。关闭性别／色块标记只改变显示方式，不改变计算。这些区间来自参考界面的复现，不是医疗标准；音高也不能单独决定声音的性别感知。输入电平为 **dBFS**，不是经校准的声压级 dB SPL。噪声、气声与多个声源会影响分析效果。

## 本地数据

音频在本机处理，应用不上传录音。实时页最多保留 30 秒内存缓冲。长文录音使用临时 WAV 文件，离开分析页时清理；异常退出可能留下临时文件，由系统后续清理。导入的源文件不会删除，导出的文件保留在用户指定位置。

设置、自定义长文及建议语句库均保存在本地，中文与英文内容分别存储。

## 自动检查

请用 PowerShell 7，在独立进程中分别运行：

```powershell
pwsh -NoProfile -File tests/Test-PitchDetector.ps1
pwsh -NoProfile -File tests/Test-MusicalTone.ps1
pwsh -NoProfile -File tests/Test-RecordingAnalysis.ps1
pwsh -NoProfile -File tests/Test-PlaybackTimeline.ps1
pwsh -NoProfile -File tests/Test-Settings.ps1
```

检查覆盖音高检测、参考音、完整文件分析、时间轴坐标、比例尺、本地化和按语言隔离的存储。设置测试使用存储适配器替身；真实麦克风、设备路由、回听及安装仍需 Windows 硬件测试，参见[人工检查清单](docs/manual-checks.md)。

## 项目结构

- `Audio/`：采集、音高检测、参考音生成、播放和录音分析。
- `Settings/`：偏好设置、本地化、比例尺和练习内容。
- `*_Page.xaml` / `*_Page.xaml.cs`：应用页面与交互逻辑。
- `Assets/`：应用图标、磁贴和播放控件资源。
- `tests/`：自动检查。
- `docs/`：人工检查清单、参考截图与图标设计说明。
