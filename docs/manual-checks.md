# Windows 实机验收

这些项目需要实际麦克风和扬声器，不能由合成信号测试代替。

1. 启动应用，默认不采集声音。点击开始，首次按 Windows 提示授权麦克风。
2. 拒绝权限时出现可读错误；授权后可重新开始。
3. 安静时音高显示 —；说话时曲线更新，暂停后曲线停止。
4. 回听 5 / 10 / 20 / 30 秒；不足所选时长时播放实际已有片段。无录音时给出提示。
5. 播放时停止采集，无反馈循环；播放结束或失败后可以继续练习。
6. 播放参考音，检查所选频率与听感，开头结尾没有明显爆音。
7. 清除后不可再回听；切换设置再返回后同样没有旧录音。
8. 挂起 / 恢复应用，确认采集停止、缓存清空、可重新开始。
9. 权限提示或音频初始化期间切换页面 / 挂起，确认不在后台继续采集。
10. 设置回听时长，重启后设置保留。没有区间或颜色修改入口。
11. 改变窗口大小，检查文字、图表、按钮可见并可滚动。
12. 使用内置、USB、蓝牙输入设备分别验证；无设备或设备拔出后检查是否能重新进入练习。

尚未完成实机交互验收，不应把编译成功当作这些项目已通过。

## 长文分析验收

1. 从汉堡菜单进入「分析」，确认实时采集已释放麦克风；新页面呈现深色文章区和红色录音按钮。
2. 录制超过 30 秒，停止后等待文件分析；总时长应覆盖整段录音，回听也包含开头。
3. 全静音应显示无可靠音高，不应出现 100% 男性区间。
4. 导入 PCM 16 位 WAV，检查结果；取消选择不丢失现有录音，错误格式显示说明。
5. 回听、停止回听、返回朗读页、再录一段均可操作。记录过程中不允许导入或重复启动。
6. 保存录音，离开页面后确认保存文件和导入文件仍在；仅应用自建的临时录音被清理。
7. 录制/分析时切换页面或挂起应用，不应后台继续录音；恢复后可分析已保存片段。
8. 对照 docs/reference-analyse1.png / reference-analyse2.png 检查布局、颜色、圆形读数和统计表。

## 音调页验收

1. 侧栏入口和标题为「音调」，仍使用汉堡菜单；不再出现频率滑块和播放 3 秒按钮。
2. 发声时上方实时显示 Hz 和最近音名；安静时显示 `---`。
3. 按住任意音符，参考音持续播放，同时上方分析仍更新；松开停止。
4. 快速点击、切换音符、移出窗口后松开、键盘空格/回车、Alt+Tab、页面切换和挂起均不应留下持续发声。
5. 耳机播放参考音时，用另一音高说话，确认显示跟随麦克风而非所按的键。
6. 原音高页回听依旧暂停采集，结束后自动恢复，不受参考音改动影响。

## 设置验收

1. 切换 English：设置页和侧栏文字更新；Voice 连续切换至少八次语句应全部为英文。切回中文后重复检查。
2. 中英文分别保存不同长文，切换语言再进入分析页，确认只出现当前语言保存的文章。保存超过 8 KB 的文章，重启后内容完整。
3. 关闭性别标记：检查实时图、音调键盘、统计和分析结果均无性别颜色/分类标签；分析数值和百分比不变。重新打开后恢复。
4. 切换 ERB / Mel / Linear，检查曲线、50 Hz 网格、色带边界和结果页标记按同一比例尺移动；Hz 读数不变。
5. 分别选择内置、USB 或蓝牙麦克风，进入 Voice 和分析页检查实际录音来源。
6. 选择不同扬声器/耳机，检查按住音符、短时回听和长文回听均从指定设备输出。
7. 拔出指定设备后重新进入录音/播放，确认提示不可用；设置页刷新后能看到不可用标识并切换系统默认。
8. 重启应用，检查语言、标记、比例尺、回听时长、长文和设备选择保留。

## 主页时间轴与回听

1. 新设置默认 ERB；依次切换 Mel、Linear，观察相同 Hz 的网格、曲线与色带位置变化。
2. 开启主页，灰线从右向左移动；默认 10 秒后抵达最左。静音也计入录音时间。
3. 录制不足 10 秒时点击回听，红线从灰线开始向右移动；满 10 秒则从最左开始。
4. 分别在刚开始回放、播放一半、接近结尾时再点回听：声音立即停止，旧录音和曲线清空，灰线从右侧重新向左移动；再次回听只能听到新录音。
5. 播完自动恢复录音；点击“继续录音”可提前退出回听。清除、离页、挂起恢复后不应残留旧时间轴。
6. 切换 5/20/30 秒回听窗口，重复短录音与满窗口验证；窗口缩放后标记仍与曲线对齐。
